## 三、滑动展示交互方案

精选项目采用与 InkPartner“界面展示”一致的交互模型，但卡片内容继续沿用 BEINING.UK 的项目结构和视觉风格。

### 展示方式

- 4 张项目卡只保留一组，横向轨道中不会出现重复项目。
- 桌面端同时露出多张卡片，移动端每张卡约占视口宽度的 78%～84%，让下一张卡保留可见边缘，提示用户可以继续滑动。
- 轨道两端保留渐隐遮罩，左右两侧使用圆形翻页按钮。
- 项目卡继续展示封面、分类、状态、标题、摘要、最多 6 个标签、外部链接和“查看详情”。
- 首页精选区使用滑动轨道；“全部项目”页面仍使用现有网格，不受影响。

### 自动与手动滑动

- 页面加载后立即以约 24px/s 的速度移动；到达轨道末端后反向移动，避免复制卡片或出现空白。
- 左箭头把轨道向左推进，右箭头把轨道向右退回；到达边界时停止，不反向跳转。
- 支持鼠标横向滚动、触摸拖动和手机手势滑动。
- 滑动区域获得焦点后，支持键盘 `←` / `→` 控制。
- 鼠标进入任意项目卡时暂停自动移动，移出项目卡后立即恢复。
- 触摸、滚轮或手动翻页时暂停自动移动，停止操作约 5 秒后恢复；进入页面后不等待交互，立即开始移动。
- 当系统启用“减少动态效果”时，关闭自动动画并保留手动滑动。

### 封面导航

- 点击项目封面直接进入对应的站内项目详情页，不打开图片预览。
- 标题、摘要和“查看详情”同样进入对应项目详情页。
- 项目详情页不显示“同类项目”或其他相关推荐区。
- 页面和无障碍树中都只保留 4 张唯一项目卡。

### 实现边界

- 不引入 React 或新的前端依赖；使用 Hugo 模板、现有 CSS 和一份仅首页加载的原生 JavaScript 实现。
- 轨道改用合成层 `translate3d` 动画；移动端关闭边缘遮罩，并使用轻量封面，降低重绘与图片解码负担。
- 不直接复制 InkPartner 的品牌颜色、字体或页面容器，保持 BEINING.UK 当前设计系统。
- 不使用图片热链，所有封面继续保存在本站项目 leaf bundle 或静态资源中。

## 四、项目详情页短说明

首页卡片会进入站内详情页。新建项目页时建议保持内容简短，使用以下说明。

### Air780EG 自行车定位器

#### Overview

Air780EG 自行车定位器把 LTE Cat.1 联网、北斗/GPS 双模卫星定位和 LBS 定位集成到低功耗设备中。设备可通过绑带安装在自行车上，并在微信小程序中查看位置、电量和历史轨迹。

#### Hardware / software

硬件采用 Air780EG 模组、有源 GNSS 天线及低噪声放大方案，并针对电池供电和联网峰值电流设计电源切换。平台支持设置位置上传间隔，也可按公开说明接入物联网平台或自建服务。

#### 状态说明

本页只概括已在 OSHWHub 公开的设计和能力，不宣称当前代码仍全部开放，也不扩展页面未确认的续航或定位精度数据。

### 4G 智能远程通断器

保留现有详情页主体，只更新首页摘要、排序和技术标签。现有详情已经准确覆盖以下内容：

- Air780E / EC618 的 4G 联网；
- 4 路继电器控制；
- SHT30 温湿度采集；
- MQTT、小程序和私有服务器控制；
- 433MHz 本地遥控；
- 强电使用风险与停止公开维护状态。

### IELTS TODAY

#### Overview

IELTS TODAY 是面向雅思口语练习与教学管理的辅助评测平台。学生端覆盖口语练习、录音和反馈报告，教师端提供学生管理、音频评测、历史记录、人工复核与报告导出。

#### Engineering

项目包含 React / TypeScript 前端、Python / FastAPI 服务端、实时音频交互、录音处理、AI 语音证据与多维评测，以及面向生产环境的权限、数据和部署流程。

#### 使用边界

所有结果均为 AI 辅助反馈，不表述为 IELTS 官方成绩；卡片和详情页不展示价格、生产账户、内部诊断数据或供应商密钥信息。

### InkPartner

#### Overview

InkPartner 是面向个人开源显示项目的内容型网站。当前主项目为 RLCD 反射式液晶桌面信息屏，用真实设备界面展示天气概览、时钟、日历、温度趋势、逐小时天气、日出日落和系统信息。

#### Engineering

网站采用 React、TypeScript 与 Vite，项目和站点信息由独立内容配置驱动，并使用 AVIF / WebP 响应式图片适配不同屏幕。文档、在线刷机与联系方式目前仍是状态页，因此详情文案不把这些入口描述成已经开放的功能。
